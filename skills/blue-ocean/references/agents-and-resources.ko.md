# 에이전트 모델과 자원 배정

## 자원 인지형 병렬 실행

실제 병목을 줄이는 독립 작업에 사용 가능한 승인 에이전트·프로세스를 활용합니다. 고정된 에이전트 수를 만들거나 의존 작업을 병렬화하지 않습니다.

- 큰 병렬 작업 전에 에이전트 슬롯, 논리 CPU 수, CPU·메모리 부하, 빌드·테스트 구조를 확인합니다. 사용자가 전용 최대 활용을 요청하지 않으면 데스크톱 반응성을 유지합니다.
- 독립 조사·분리된 구성요소·테스트 묶음·검토를 병렬화합니다. 아키텍처 결정·공유 파일·마이그레이션·의존 빌드는 순차 처리하고 필요하면 빌드 출력을 분리합니다.
- 동시 실행 수를 용량에 맞추고 메모리 압박·불안정·반응성 저하 시 줄입니다. 실행 상태를 확인하여 중복·차단·실패·자원 부족 작업을 중지·축소하되 통합·검증·정리 자원은 남깁니다.
- 기존 도구·계정 한도를 사용하며 새 API 키·유료 작업·외부 서비스 연결은 별도 사용자 승인을 받습니다.
- 중요한 동시 실행·자원 선택과 검증 담당을 로드맵에 기록합니다. 중첩·타이핑 작업까지 [PM 관리](pm-control.ko.md)의 업무지시·보고·토큰 할당량·예측을 적용합니다.

## 역할별 에이전트 모델

PM만 **GPT-6.1 Sol** (`gpt-6.1-sol`), 설계자·개발자·타이핑·QC·조사·빌드·테스트 등 나머지 모든 블루오션 역할은 **GPT-6.1 Terra** (`gpt-6.1-terra`)를 사용합니다. 작업마다 다시 묻지 않고 이 배정을 재사용합니다.

- 생성 시 역할별 모델을 명시하고 도구의 모델 재정의·문맥 조건을 따릅니다. 새 문맥이 필요하면 독립적으로 이해할 수 있는 인계를 제공합니다. 상속만 지원하면 부모 모델을 확인한 뒤 준수를 보고합니다.
- 필요한 모델이 불가하면 해당 배정을 대기 상태로 두며 임의 대체하지 않습니다. 프롬프트만으로 실행 중인 세션이 전환됐다고 주장하지 않고 필요한 클라이언트 변경·새 세션을 안내합니다.
- 작업 배정에 역할·실제 모델을 기록하고 모르면 미확인으로 표시합니다. 모델 배정은 명시적 사용자 지시가 있을 때만 바꿉니다.

## 문맥과 인계

소유권은 [개발 역할](delivery.ko.md#역할과-책임)과 PM 업무지시를 따릅니다. 작업자에게 범위가 정해진 목표, 필요한 파일·발췌, 제약, 예상 자원, 완료 신호를 제공합니다. 변경 없는 파일 참조·이전 요약을 재사용합니다. 완료 시 변경·검증·차단·책임자 결정을 반환하고 공유 파일은 순차 편집하며 가능한 경우 QC를 독립적으로 유지합니다.
