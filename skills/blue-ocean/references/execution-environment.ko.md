# 실행 환경과 유지보수

작업자 설정, 환경 실패 분석, Codex 연동 변경 또는 요청된 유지보수에 해당하는 절만 읽습니다. 관측 결과는 기존 작업 기록·로드맵에 남기며 별도 원장을 필수화하지 않습니다.

## Windows·WSL·작업 트리

- 편집·빌드 전에 실제 저장소 루트, 브랜치/작업 트리, 셸을 확인합니다. 가능한 경우 `git rev-parse --show-toplevel`과 `git status --short`를 사용합니다. Windows/WSL 경로는 해당 환경에서 해석하며 작업 제목이나 상속된 작업 디렉터리만으로 체크아웃을 단정하지 않습니다.
- 기존 솔루션-프로젝트 구성과 도구를 따릅니다. MSBuild/Visual Studio 또는 dotnet과 필요한 Debug/Release·플랫폼 구성을 확인합니다. 동시 빌드가 같은 중간·출력 파일을 덮어쓰면 경로를 분리하고, 분리가 어려우면 빌드를 순차 실행합니다.
- 작업 트리는 미커밋 파일·무시된 설정·설치 의존성·환경 변수를 자동 상속하지 않습니다. 배정된 작업에 필요한 사전 조건만 확인합니다. 로컬 수정·자격 증명을 보존하며 비밀정보 복사나 사전 조건 설치를 임의로 수행하지 않습니다.
- 앱 업데이트·재접속 뒤에는 재시도 전에 실제 샌드박스/도구 오류와 체크아웃을 확인합니다. 실행 파일 부재·권한 실패·환경 연결 끊김과 제품 결함을 구분합니다. 허용된 더 좁은 동작이나 지원되는 권한 요청 경로를 사용합니다. 자동 승인 검토가 거절하면 동작·이유를 알리고 같은 거절 동작 반복이나 권한 완화로 우회하지 않습니다.
- 인계에는 체크아웃·빌드 대상/구성·마지막 관측 결과·다음 작업을 기록합니다. 하네스 작업은 이전 검증을 신뢰하기 전에 [resume과 재검증](harness.md)을 수행합니다.

## 모델·속도·연동 호환성

- 모든 역할은 `gpt-6.1-sol`을 유지합니다. 에이전트·스크립트·예약 작업을 구성할 때 실제 클라이언트/워크스페이스 가용성을 확인합니다. 프롬프트에 모델명을 적은 것만으로 실행 모델을 입증하지 않으며 불가·미확인은 정확히 보고합니다.
- GPT-5.5는 2026년 10월 14일 ChatGPT 로그인 방식 Codex에서 종료됐으며 API 키 세션에는 해당하지 않습니다. 기존 설정을 이전할 때 영향받는 모델 선택값만 확인합니다.
- Ultrafast는 GPT-6.1 Sol의 선택적 클라이언트/요금제 기능입니다. 추천·활성화 전에 최신 공식 가용성과 사용 조건을 확인합니다. 작업에 적절한 모델·추론 설정을 유지하고 지시문만으로 활성화를 주장하지 않습니다. 기존 선택과 설정·지출 변경 권한을 따릅니다.
- 사용자 정의 Codex 연동을 갱신할 때 실제 사용 명령·런타임을 확인합니다. `codex mcp-server`와 `codex-mcp-server`는 2026년 9월 5일 제거됐습니다. 공식 대안인 app server는 실험 기능이므로 현재 계약을 검토하고 운영 지원 기능으로 설명하지 않습니다. 외부 MCP 서버 연결 기능은 유지됩니다. 제거된 명령을 쓰지 않으면 이전할 필요가 없습니다.

## 요청된 코드 정리와 CI 작업

- 삭제·CI 수정 전에 요청 범위와 관측할 동작을 정합니다. 기존 근거와 영향받는 빌드·테스트를 재사용하며 일반 기능 작업을 임의 정리 작업으로 확장하지 않습니다.
- C++/MFC는 메시지 맵·리소스 ID·export/ABI 심볼·동적 로드·설정 경로를 확인합니다. C#은 reflection·XAML binding·직렬화·공개 계약을 고려합니다. 텍스트 검색 결과가 없다는 이유만으로 미사용을 단정하지 않습니다.
- 삭제 후보별 근거와 불확실성을 기록하고 의도된 복구·호환 경로를 보존하며 근거 부족 후보는 보류합니다. 검토 가능한 단위로 수정하고 영향받는 Debug/실제 동작 또는 CI를 검증합니다. 코드 감소·CI 속도 향상만으로 동작 보존을 주장하지 않습니다.
