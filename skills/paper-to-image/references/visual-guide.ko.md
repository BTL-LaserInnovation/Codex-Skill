# 초등학생과 중학생을 위한 그림 안내

## 질문에 답하는 그림 고르기

| 논문 내용 | 그림 방식 | 피할 표현 |
| --- | --- | --- |
| 절차나 시스템 | 구체적인 사물이 담긴 몇 개의 순서 있는 장면 | 설명 없는 화살표가 얽힌 구조 |
| 조건을 통제한 비교 | 같은 축척의 두 집단을 나란히 배치 | 크기가 다른 아이콘으로 수량 비교 |
| 개수나 비율 | 작은 표본은 항목당 아이콘 하나, 또는 문구가 있는 막대 차트 | 실제 데이터와 다른 장식용 수량 |
| 제안된 작동 원리 | “제안된 설명”이라고 표시한 간단한 도식 | 추측을 관찰된 사건처럼 표현 |
| 여러 논문 | 출처를 구분하고 비교 가능한 항목을 배치 | 다른 대상이나 단위를 설명 없이 합치기 |

크고 명확한 요소를 적은 수로 배치하고, 읽는 방향은 하나로 하며 배경을 단순하게 만든다. 글자를 줄여 끼워 넣지 말고 문구를 줄이거나 이미지를 나눈다. 한국어에는 한글을 지원하는 글꼴을 사용한다. 색상은 보조 수단이다. 집단 이름을 표시하고 필요하면 모양도 구분한다.

정량적 차트에는 단위, 분모, 관련 조건을 표시한다. 공통 축척을 사용하고 일반적인 개수 막대는 0에서 시작한다. 수치로 표현하는 불확실성은 원문에 있을 때만 표시한다. 그림을 수치화하여 추정한 값은 추정치임을 명시하며 정확한 원문 데이터처럼 제시하지 않는다.

## 그림 제작 명세 준비하기

그리기 전에 독자, 질문, 핵심 메시지, 장면 순서, 확인된 사실, 눈에 보이는 불확실성, 출처 위치, 사용할 크기를 정한다. 짧은 내부 메모로 충분하며 명세가 이미지를 대신하지 않는다.

장면마다 구체적인 상황, 짧은 문구, 근거가 있는 메시지가 필요하다. 원문에 근거한 내용과 설명용 장식을 구분한다. 이미지 생성 시 이러한 제약을 명시하고 필요하면 정확한 문구를 따로 추가할 공간을 확보한다. 실제 이미지를 확인한다. 올바른 프롬프트가 올바른 결과를 보장하지는 않는다.

익숙한 비유의 동작이 설명하려는 부분과 맞을 때 사용한다. 체는 크기에 따른 분리를 설명할 수 있지만 실제 막이 오직 크기로만 물질을 거른다고 암시해서는 안 된다. 중요한 차이를 설명한다. 요정이나 의도적인 행동이 분자가 생각하거나 선택한다고 암시하지 않도록 한다.

## 예시: 가상의 씨앗 실험

아래 내용은 만든 수업 예시이며 실제 논문이나 과학적 발견이 아니다.

제공된 발췌문: 2쪽에는 집단별 녹두 20개, 같은 수분 조건, 주변 온도 22°C, A 집단에 하루 2시간 램프를 비춘 방법이 나온다. 4쪽 표 1에는 5일 뒤 A 집단에서 14개, B 집단에서 10개의 싹이 난 결과가 나온다. 5쪽에는 소규모 예비 실험이라는 한계가 나온다. 무작위 배정 여부는 명시되지 않았고 통계 검정 결과가 없으며 씨앗 표면 온도도 측정하지 않았다.

| 주장 | 출처 | 이미지에서 표현하기 |
| --- | --- | --- |
| 씨앗 20개씩 두 집단; A에만 램프 사용 | 2쪽 | 같은 쟁반, “하루 2시간 빛” / “램프 없음” 문구 |
| 5일 뒤 싹 14개와 10개 | 4쪽 표 1 | 집단별 아이콘 20개, 싹은 정확히 14개 / 10개; “5일 뒤 관찰” |
| 예비 실험의 한계 | 5쪽 | “아직 더 실험해야 해요.”; 자세한 내용은 분석에 포함 |
| 씨앗을 깨우는 요정 | 원문 근거가 아닌 비유 | 선택적으로 작은 삽화를 넣고 “이해를 돕는 비유”라고 표시 |

읽기 쉬운 네 장면 이미지는 다음처럼 표현할 수 있다.

1. **질문:** “빛을 받으면 싹이 더 많이 날까?” — 씨앗과 램프를 그린다.
2. **실험:** “씨앗을 20개씩 나눴어요.” — 같은 쟁반 두 개에 램프 조건과 “물과 주변 온도는 같아요.”를 붙인다.
3. **관찰:** “5일 뒤 싹을 세었어요.” — “빛 받은 쪽: 14개”, “램프 없는 쪽: 10개”를 표시한다.
4. **핵심:** “이번엔 4개 더 싹이 났어요.”와 “아직 더 실험해야 해요.”를 표시한다.

네 번째 장면의 불확실성도 읽을 수 있게 만든다. 이미지가 복잡하면 정확한 단위, 주변 온도, 출처 정보는 캡션에 담는다. 중학생용 설명에는 측정하지 않은 온도 차이나 우연도 영향을 줄 수 있음을 설명한다. “두 배”, “빛 때문에 확실히 이렇게 됐다”, “모든 씨앗에 효과가 있다”라고 쓰지 않는다. 두 집단은 70%와 50%이며 20퍼센트포인트 차이, 비율로는 1.4배이다. 어린 독자에게는 개수로 설명하는 것이 더 쉽다.

## 최종 확인

아이콘 수와 문구를 원문 기준으로 확인한다. 화살표 의미와 읽는 순서를 확인한다. 어린이가 긴 문단 없이 질문, 비교, 결과, 불확실성을 파악할 수 있어야 한다. 원본 코드뿐 아니라 내보낸 파일을 연다. 래스터 변환으로 글자나 배치가 바뀔 수 있다면 변환본도 따로 확인한다. SVG만 만들고 확인했다면 그대로 보고하고 PNG까지 만들었다고 말하지 않는다.
